## 背景、前置与范围

区域搜索重建、按页结果聚合与增量同步已有完成记录。当前 AI 复用搜索排序及摘要，但 WikiTools 丢失规范标题、命中范围和章节导航，省略数量时继承手动搜索默认 50。既有 Read 已支持章节、父条件、续读及版本校验；本次复用这些能力。

授权范围为 Application 独立 AI 设置与查询入口、WikiTools 导航、Python 解析/投影/提示词、定向测试和持续规范。数据库、索引、搜索评分、同步、Viewer、会话格式、运行限位、依赖、工具数量保持不变；不增加跨轮缓存。新增设置控件仅登记到后续维修计划。

## 方案与接口

1. `ApplicationPreferences.AiSearchLimit` 默认 5，范围 1..100；缺失字段沿用默认，非法持久值修复，非法显式保存拒绝且不写入。查询用例增加 `SearchForAiAsync` 薄入口；显式 max_results 优先，省略时读取最新 AI 设置。手动 SearchLimit 默认仍为 50。设置页现有 with 保存方式保留未展示字段。
2. Search 保留原字段与顺序，新增 canonical_title、match_scope（same_region / same_section / same_page / partial）、matched_sections（section_path / anchor）和 matched_sections_truncated。代表区域在前，其余沿 EvidenceRegions 顺序，按路径和 Anchor 去重；最多 5 项、合计 2048 Unicode scalar，超限省略整项并标记，不截断 Anchor；不输出 RegionId 或区域正文。
3. Python 要求导航字段全部有效或全部缺失；旧响应全部缺失时退回原读取流程，部分缺失/空值/非法 scope/重复或超限拒绝。模型保留导航，继续去掉 highlights。
4. Agent 默认省略 max_results 使用用户配置，必要时显式扩大；搜索使用实体/别名/主题关键词。以规范标题和原 Anchor 定向 Read，无 Anchor 或目标缺失时回到 page/catalog。摘要与导航不是事实证据；完整列表和比较需覆盖所有相关部分。过期 continuation 重新读取，协议字段不进入最终回答。

### 采用的提示词组织

在现有 `_AGENT_INSTRUCTIONS` 的检索策略附近加入紧凑的意图表，复用现有证据、导航、重试和完整性规则，避免把附件第3节整段重复粘贴。按意图归并、不设词条数量指标；同一行的词按问题选用，不全部堆入 query。以下保留调研候选分组；实际实施按已有证据收束，未纳入波数 query，内容/渔获/机制等仅作返回目录选择，入住/持续时间/生长/收获等用于 focus，不将全部候选提升为搜索词：

| 意图分组 | 调研中的候选词 | 采用边界 |
| --- | --- | --- |
| 合成与制作链 | 制作、配方、制作树、制作站 | 合为一条；直接配方、完整链和制作设施分别选词，不能互相替代。 |
| 掉落与奖励 | 掉落、宝藏袋 | 合并相关问法但保留普通掉落与开袋内容区别；通用掉落页不能证明具体 Boss 的全部奖励。 |
| 召唤与事件 | 召唤、召唤和生成、生成条件、内容、波数 | 实体优先；章节存在与否以返回目录为准，结束条件可能在导语；波数等未在摘要中充分展示收益的词先核对再纳入。 |
| 装备属性与效果 | 套装、功能 | 按实际问题选择，不能把套装奖励等显示文字当作固定 anchor。 |
| 药水与状态 | 制作、配方、增益药水、增益、减益、持续时间 | 制作问题才优先制作/配方；效果和持续时间问题优先相关正文/状态表，不能照搬“具体药水一律先读制作”的候选规则。 |
| NPC 条件与偏好 | 入住、出售物品、快乐、生活偏好 | 区分 query、focus 和目录用途；入住常在正文，不强求同名章节。 |
| 环境与地层 | 生物群系、地层 | 是不同主题，不是同义词；条件问题按需分别定位。 |
| 钓鱼与容器奖励 | 钓鱼、渔获、宝匣、机制；宝箱及其返回目录 | 宝匣与宝箱分别按对象选词，不能互换；目录用词不自动成为有效 query。 |
| 种植 | 具体植物/种子、种植盆；生长、收获 | 具体实体优先；种植盆是样例入口，不能把全部植物问题改写为种植盆。 |

不纳入未确认的语音错词映射；“保灶带”“制作术”“药些探索”只保留在调研附件待确认项。天气、世界状态、跨版本/难度主题组合等未充分验证内容，不升级为强制检索规则。

默认策略仍为实体/别名结合必要主题词，候选表只辅助选择；已知实体页足以导航时可以只搜实体。无可用结果遵守现有至多一次缩短重试。保留默认省略 max_results、旧响应回退、成功 Read 才可作证据、八次工具调用上限和完整性检查；不增加固定工具调用或强制读无关章节。

### 与 Anchor 独立变更的关系

调研记录7次用章节显示名拼接 anchor 的失败及原样编码 anchor 成功；原验收记录6次 Search 返回真实中文 id 后 Read 未命中。两组现象来源不同，不能合并计数，也不能据此认定原缺陷已修复或都由模型猜 anchor 引起。提示词继续要求复用工具返回 anchor，缺失时回退 page/catalog；多真实 id 的兼容修复仍由 `../fix-ai-search-read-anchor-compatibility/plan.md` 管理，不在此扩大工具实现范围。
