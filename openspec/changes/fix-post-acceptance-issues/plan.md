### 完整核对周期 UI 范围（2026-09-15）

- 当前仅记录后续控件、布局与说明文案需求，不实施新界面；后续按 terraria-ui Skill 验收。
- 复用 ApplicationPreferences.WikiFullScanIntervalDays：正整数为天数，null 表示关闭定期核对，默认 14；保存通过现有设置用例，不调用同步元数据清理，不自动联网或创建后台任务。
- 当前只允许既有 SettingsViewModel 保存时保留未展示的新字段，防止用户修改主题等已有选项时重置周期；这是设置透传兼容修正，不新增控件。
- 同 Wiki 导入保留可信同步状态的行为由 Core 实现；后续如需调整导入说明，应说明仅无有效状态时首次更新完整核对，不宣称所有导入都重新建基线。

### 新增界面问题记录（2026-09-15）

- 左侧导航调整需核对当前路由、选中态、键盘导航和窄窗口布局；首页打开显示设置应复用现有启动导航状态，不创建后台任务，并在无可用 Wiki 数据时给出稳定回退。
- 收藏五角星颜色应统一使用现有主题资源或集中颜色令牌，覆盖 Wiki 阅读页、收藏列表及其他收藏入口；需同时检查浅色、深色主题和禁用态对比度。
- 数据管理页按钮调整只改变布局与视觉层级，不改变检查、更新、取消、失败恢复和进度绑定；应以用户提供的截图为问题证据，实施前读取实际 XAML/ViewModel 调用关系。
- 上述三个界面改动属于 Windows Avalonia UI 变更，实施时必须先完整读取项目 `terraria-ui` Skill 及其 Windows UI 标准，并由用户执行最终窗口验收。
